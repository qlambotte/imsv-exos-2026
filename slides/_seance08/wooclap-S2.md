# Wooclap — Correction de S.2 (QCM)

Un événement Wooclap, quatre questions **QCM à réponse unique**, une par fonction, posées juste
après le temps consacré au socle. L'énoncé de S.2 est projeté pendant le vote (slide « Quelles dérivées
as-tu trouvées ? »). Les résultats disent par où commencer la correction : on corrige d'abord la fonction
où les votes sont les plus partagés.

---

## Q1 — Le produit $f(x) = (x^{2} + 1) \cdot e^{x}$

**Type Wooclap :** QCM · réponse unique

**Énoncé à coller :**
> Que vaut $f'(x)$, pour $f(x) = \left(x^{2} + 1\right) \cdot e^{x}$ ?

**Choix :**
- (X) $(x + 1)^{2} \cdot e^{x}$
- ( ) $2x \cdot e^{x}$
- ( ) $(x^{2} + 2x) \cdot e^{x}$
- ( ) $(x^{2} + 1) \cdot e^{x}$

**Justification :** règle de Leibniz : $2x \cdot e^{x} + (x^{2} + 1) \cdot e^{x} = (x^{2} + 2x + 1) \cdot e^{x} = (x + 1)^{2} \cdot e^{x}$.
Le distracteur $2x \cdot e^{x}$ dérive chaque facteur et multiplie les dérivées ; $(x^{2} + 2x) \cdot e^{x}$ perd le $+1$ en
mettant en évidence ; $(x^{2} + 1) \cdot e^{x}$ croit que le produit se dérive comme $e^{x}$.

## Q2 — Le quotient $g(x) = \frac{2x + 1}{x - 3}$

**Type Wooclap :** QCM · réponse unique

**Énoncé à coller :**
> Que vaut $g'(x)$, pour $g(x) = \dfrac{2x + 1}{x - 3}$ ?

**Choix :**
- (X) $-\dfrac{7}{(x - 3)^{2}}$
- ( ) $\dfrac{7}{(x - 3)^{2}}$
- ( ) $2$
- ( ) $-\dfrac{5}{(x - 3)^{2}}$

**Justification :** $\dfrac{2(x - 3) - (2x + 1) \cdot 1}{(x - 3)^{2}} = \dfrac{-6 - 1}{(x - 3)^{2}}$. Le distracteur $+7$ inverse l'ordre du
numérateur ; $2$ est le quotient des dérivées $\tfrac{2}{1}$ ; $-5$ vient d'une erreur de signe en développant $-(2x + 1)$.

## Q3 — Le quotient $h(x) = \frac{\sin(x)}{x}$

**Type Wooclap :** QCM · réponse unique

**Énoncé à coller :**
> Que vaut $h'(x)$, pour $h(x) = \dfrac{\sin(x)}{x}$ ?

**Choix :**
- (X) $\dfrac{x\cos(x) - \sin(x)}{x^{2}}$
- ( ) $\cos(x)$
- ( ) $\dfrac{\sin(x) - x\cos(x)}{x^{2}}$
- ( ) $\dfrac{x\cos(x) - \sin(x)}{x}$

**Justification :** $\dfrac{\cos(x) \cdot x - \sin(x) \cdot 1}{x^{2}}$. Le distracteur $\cos(x)$ est le quotient des dérivées
$\tfrac{\cos(x)}{1}$ ; le troisième inverse l'ordre du numérateur ; le dernier oublie le carré du dénominateur.

## Q4 — La simplification $k(x) = \frac{x^{3} - 4x}{x - 2}$

**Type Wooclap :** QCM · réponse unique

**Énoncé à coller :**
> Que vaut $k'(x)$, pour $k(x) = \dfrac{x^{3} - 4x}{x - 2}$, et sur quel domaine ?

**Choix :**
- (X) $2x + 2$, sur $\mathbb{R} \setminus \{2\}$
- ( ) $2x + 2$, sur $\mathbb{R}$
- ( ) $3x^{2} - 4$, sur $\mathbb{R} \setminus \{2\}$
- ( ) $x^{2} + 2x$, sur $\mathbb{R} \setminus \{2\}$

**Justification :** $x^{3} - 4x = x(x - 2)(x + 2)$, donc $k(x) = x^{2} + 2x$ pour $x \neq 2$, et $k'(x) = 2x + 2$ ; on a divisé par
$x - 2$, donc $2$ reste exclu. Le deuxième choix élargit le domaine ; $3x^{2} - 4$ est le quotient des dérivées ;
$x^{2} + 2x$ est la fonction simplifiée, pas sa dérivée.
