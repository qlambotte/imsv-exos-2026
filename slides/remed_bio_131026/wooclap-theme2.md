## Q1 — Modélisation linéaire (Moodle P1)

**Type Wooclap :** QCM · réponse unique

**Énoncé à coller :**
> Une entreprise de location de vélos propose un tarif composé d'un montant fixe de 5 euros auquel s'ajoutent 2 euros par heure de location. On note $x$ le nombre d'heures de location et $y$ le prix total payé, en euros. Parmi les propositions suivantes, laquelle modélise correctement cette situation ?

**Choix :**
- (X) $y=2x+5$
- ( ) $y=2x$
- ( ) $y=5x+2$
- ( ) $y=5$

**Justification (à dire à voix haute après le vote) :** Partie fixe $5$ € (ordonnée à l'origine), $2$ € par heure (pente) : $y=2x+5$.

## Q2 — Résolution d'une inéquation (Moodle Q4)

**Type Wooclap :** QCM · réponse unique

**Énoncé à coller :**
> Résoudre dans $\mathbb{R}$ l'inéquation suivante :  $$3(1-2x)>x+10.$$

**Choix :**
- (X) $x < -1$
- ( ) $x > -1$
- ( ) $x < 1$
- ( ) $x > 1$

**Justification (à dire à voix haute après le vote) :** $3-6x>x+10\iff -7x>7\iff x<-1$ (division par $-7<0$ : le sens s'inverse).

## Q3 — Système non linéaire (Moodle Q2)

**Type Wooclap :** QCM · réponse unique

**Énoncé à coller :**
> Résoudre dans $\mathbb{R}^2$ le système suivant :  $$\left\{ \begin{aligned} x^2-2x-y &= 0,\\ 3x-3y &= -12. \end{aligned} \right.$$

**Choix :**
- (X) $\mathrm{Sol}=\{(-1,3),(4,8)\}$
- ( ) $\mathrm{Sol}=\{(4,8)\}$
- ( ) $\mathrm{Sol}=\{(-1,-1),(4,4)\}$
- ( ) $\mathrm{Sol}=\varnothing$

**Justification (à dire à voix haute après le vote) :** La seconde équation donne $y=x+4$. Substitution : $x^2-2x-(x+4)=0$, soit $x^2-3x-4=0$. $\Delta=9+16=25$, $x=\dfrac{3\pm5}{2}$ : $x=4$ ou $x=-1$. Alors $y=8$ ou $y=3$. $\mathrm{Sol}=\{(-1,3),(4,8)\}$.

## Q5 — Équation d'une droite (Moodle Q5)

**Type Wooclap :** QCM · réponse unique

**Énoncé à coller :**
> On considère la droite $d$ passant par les deux points  $$A=(-2,1) \qquad\text{et}\qquad B=(4,10).$$
>  Parmi les propositions suivantes, laquelle donne une équation de la droite $d$ ?

**Choix :**
- (X) $\displaystyle y=\frac{3}{2}x+4$
- ( ) $\displaystyle y=\frac{2}{3}x+\frac{7}{3}$
- ( ) $\displaystyle y=\frac{3}{2}x+1$
- ( ) $\displaystyle y=-\frac{3}{2}x-2$

**Justification (à dire à voix haute après le vote) :** $m=\dfrac{10-1}{4-(-2)}=\dfrac96=\dfrac32$. Avec $A$ : $1=\dfrac32\cdot(-2)+p$, donc $p=4$ : $y=\dfrac32x+4$.

## Q6 — Position relative de deux droites (Moodle Q3)

**Type Wooclap :** QCM · réponse unique

**Énoncé à coller :**
> Voici les équations de deux droites :  $$d_1 \equiv y=\frac{3}{2}x-1 \qquad\text{et}\qquad d_2 \equiv y=-\frac{2}{3}x+4.$$
>  Quelle est leur position relative ?

**Choix :**
- ( ) Les droites sont différentes mais parallèles.
- (X) Les droites sont orthogonales.
- ( ) Les deux équations représentent la même droite.
- ( ) Les droites ne sont ni parallèles ni orthogonales.

**Justification (à dire à voix haute après le vote) :** $m_1=\dfrac32$ et $m_2=-\dfrac23$ : $m_1\cdot m_2=-1$, donc les droites sont orthogonales.
