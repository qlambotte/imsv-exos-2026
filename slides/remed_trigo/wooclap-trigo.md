## Q1 — Angles associés : cosinus et sinus

**Type Wooclap :** QCM · réponse unique

**Énoncé à coller :**
> Quelles sont les valeurs de $\cos 150°$ et de $\sin 150°$ ?

**Choix :**
- ( ) $\cos 150° = \dfrac{\sqrt3}{2}$ et $\sin 150° = \dfrac12$
- (X) $\cos 150° = -\dfrac{\sqrt3}{2}$ et $\sin 150° = \dfrac12$
- ( ) $\cos 150° = -\dfrac12$ et $\sin 150° = \dfrac{\sqrt3}{2}$
- ( ) $\cos 150° = -\dfrac{\sqrt3}{2}$ et $\sin 150° = -\dfrac12$

**Justification (à dire à voix haute après le vote) :** $150° = 180° - 30°$ : deuxième quadrant, angle aigu $30°$ ; le cosinus est négatif, le sinus positif : $\cos 150° = -\dfrac{\sqrt3}{2}$ et $\sin 150° = \dfrac12$.

## Q2 — Angle aigu avec l'axe des x

**Type Wooclap :** QCM · réponse unique

**Énoncé à coller :**
> Un vecteur fait un angle $\theta = 210°$ avec l'axe des $x$. Quel angle aigu fait-il avec l'axe des $x$ ?

**Choix :**
- (X) $30°$
- ( ) $60°$
- ( ) $150°$
- ( ) $210°$

**Justification (à dire à voix haute après le vote) :** $210° = 180° + 30°$ : le vecteur est dans le troisième quadrant et fait un angle aigu de $30°$ avec l'axe des $x$.

## Q3 — De la norme et de l'angle aux coordonnées

**Type Wooclap :** QCM · réponse unique

**Énoncé à coller :**
> Un vecteur de norme $8$ fait un angle de $135°$ avec l'axe des $x$. Quelles sont ses coordonnées ?

**Choix :**
- ( ) $(4\sqrt2,\ 4\sqrt2)$
- ( ) $(-4\sqrt2,\ -4\sqrt2)$
- (X) $(-4\sqrt2,\ 4\sqrt2)$
- ( ) $(-4,\ 4)$

**Justification (à dire à voix haute après le vote) :** $8\,(\cos 135°,\ \sin 135°) = 8\left(-\dfrac{\sqrt2}{2},\ \dfrac{\sqrt2}{2}\right) = (-4\sqrt2,\ 4\sqrt2)$.

## Q4 — Angle d'un vecteur : quadrant et tangente

**Type Wooclap :** QCM · réponse unique

**Énoncé à coller :**
> Quel angle $\theta \in [0°,\ 360°[$ le vecteur $\vec w = (-3,\ 3\sqrt3)$ fait-il avec l'axe des $x$ ?

**Choix :**
- ( ) $60°$
- ( ) $240°$
- ( ) $300°$
- (X) $120°$

**Justification (à dire à voix haute après le vote) :** signes $(-, +)$ : deuxième quadrant ; $\tan\theta = -\sqrt3$ donne un angle aigu de $60°$ ; donc $\theta = 180° - 60° = 120°$.

## Q5 — Coordonnée d'une vitesse : sinus ou cosinus ?

**Type Wooclap :** QCM · réponse unique

**Énoncé à coller :**
> Un jet d'eau sort à la vitesse de $12$ m/s en faisant un angle de $20°$ avec la **verticale**. Quelle est la coordonnée **verticale** de sa vitesse ?

**Choix :**
- (X) $12 \cos 20°$ m/s
- ( ) $12 \sin 20°$ m/s
- ( ) $12 \tan 20°$ m/s
- ( ) $\dfrac{12}{\cos 20°}$ m/s

**Justification (à dire à voix haute après le vote) :** l'angle est mesuré depuis la verticale : la coordonnée verticale est le côté adjacent à l'angle, donc $12 \cos 20°$.

## Q6 — Norme et angle d'un vecteur

**Type Wooclap :** QCM · réponse unique

**Énoncé à coller :**
> Soit $\vec w = (-\sqrt3,\ -1)$. Quelle est sa norme et quel angle $\theta \in [0°,\ 360°[$ fait-il avec l'axe des $x$ ?

**Choix :**
- ( ) Norme $2$ et $\theta = 30°$
- ( ) Norme $2$ et $\theta = 150°$
- (X) Norme $2$ et $\theta = 210°$
- ( ) Norme $4$ et $\theta = 210°$

**Justification (à dire à voix haute après le vote) :** $\left\Vert \vec w \right\Vert = \sqrt{3 + 1} = 2$ ; signes $(-, -)$ : troisième quadrant ; $\tan\theta = \dfrac{1}{\sqrt3}$ donne un angle aigu de $30°$ ; donc $\theta = 180° + 30° = 210°$.

## Q7 — Valeur du sinus dans le quatrième quadrant

**Type Wooclap :** QCM · réponse unique

**Énoncé à coller :**
> Quelle est la valeur de $\sin 300°$ ?

**Choix :**
- ( ) $\dfrac{\sqrt3}{2}$
- (X) $-\dfrac{\sqrt3}{2}$
- ( ) $-\dfrac12$
- ( ) $\dfrac12$

**Justification (à dire à voix haute après le vote) :** $300° = 360° - 60°$ : quatrième quadrant, angle aigu $60°$ ; le sinus est négatif : $\sin 300° = -\sin 60° = -\dfrac{\sqrt3}{2}$.

## Réserve 1 — Coordonnées dans le quatrième quadrant

**Type Wooclap :** QCM · réponse unique

**Énoncé à coller :**
> Une force de norme $6$ N fait un angle de $300°$ avec l'axe des $x$. Quelles sont ses coordonnées ?

**Choix :**
- (X) $(3,\ -3\sqrt3)$
- ( ) $(3\sqrt3,\ -3)$
- ( ) $(3,\ 3\sqrt3)$
- ( ) $(-3,\ -3\sqrt3)$

**Justification (à dire à voix haute après le vote) :** $6\,(\cos 300°,\ \sin 300°) = 6\left(\dfrac12,\ -\dfrac{\sqrt3}{2}\right) = (3,\ -3\sqrt3)$.

## Réserve 2 — Tangente d'un angle associé

**Type Wooclap :** QCM · réponse unique

**Énoncé à coller :**
> Quelle est la valeur de $\tan 135°$ ?

**Choix :**
- ( ) $1$
- ( ) $-\dfrac{\sqrt2}{2}$
- (X) $-1$
- ( ) $\dfrac{\sqrt2}{2}$

**Justification (à dire à voix haute après le vote) :** $\tan 135° = \dfrac{\sin 135°}{\cos 135°} = \dfrac{\sqrt2/2}{-\sqrt2/2} = -1$.

## Réserve 3 — Angle d'un vecteur sur un axe

**Type Wooclap :** QCM · réponse unique

**Énoncé à coller :**
> Quel angle $\theta \in [0°,\ 360°[$ le vecteur $(0,\ -5)$ fait-il avec l'axe des $x$ ?

**Choix :**
- ( ) $90°$
- ( ) $180°$
- ( ) $0°$
- (X) $270°$

**Justification (à dire à voix haute après le vote) :** le vecteur $(0,\ -5)$ pointe vers le bas, le long de l'axe des $y$ négatif : $\theta = 270°$.

## Réserve 4 — Coordonnée horizontale depuis la verticale

**Type Wooclap :** QCM · réponse unique

**Énoncé à coller :**
> Une force de norme $50$ N fait un angle de $30°$ avec la **verticale**. Quelle est la norme de sa coordonnée **horizontale** ?

**Choix :**
- ( ) $25\sqrt3$ N
- (X) $25$ N
- ( ) $\dfrac{50\sqrt3}{3}$ N
- ( ) $50$ N

**Justification (à dire à voix haute après le vote) :** l'angle est mesuré depuis la verticale : la coordonnée horizontale porte le sinus, donc $50 \sin 30° = 25$ N.
