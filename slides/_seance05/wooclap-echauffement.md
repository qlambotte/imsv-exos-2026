# Wooclap — Échauffement (QCM)

Un seul événement Wooclap, deux questions **QCM à réponse unique**, dans l'ordre ci-dessous.
Les distracteurs correspondent aux erreurs classiques. Durée visée : 4 à 5 minutes sur papier
pour les deux questions, puis le vote. Les questions figurent uniquement dans les slides.

---

## Q1 — Croissante ou décroissante

**Type Wooclap :** QCM · réponse unique

**Énoncé à coller :**
> Pour chacun des graphes A, B et C projetés, la fonction est-elle croissante, décroissante, ou ni l'une ni l'autre ?

**Choix :**
- (X) A : croissante ; B : décroissante ; C : ni l'une ni l'autre
- ( ) A : décroissante ; B : croissante ; C : ni l'une ni l'autre
- ( ) A : croissante ; B : décroissante ; C : croissante
- ( ) A : décroissante ; B : décroissante ; C : ni l'une ni l'autre

**Justification (à dire après le vote) :** on lit chaque graphe de gauche à droite. A monte, donc
la fonction est croissante, même si ses valeurs sont négatives ; B descend, donc elle est
décroissante, même si ses valeurs sont positives ; C descend puis monte. Le deuxième choix confond
le sens de variation avec le signe des valeurs (courbe sous l'axe lue comme « décroissante ») ;
le troisième ne regarde que la fin de la courbe C ; le quatrième lit A de droite à gauche.

## Q2 — Retrouver l'entrée à partir de la sortie

**Type Wooclap :** QCM · réponse unique

**Énoncé à coller :**
> La relation $A = 2C + 1$ donne $A$ à partir de $C$. Quelle valeur de $C$ donne $A = 7$ ?

**Choix :**
- (X) $C = 3$
- ( ) $C = 2{,}5$
- ( ) $C = 4$
- ( ) $C = 6$

**Justification :** $7 = 2C + 1$, donc $6 = 2C$ et $C = 3$. Le distracteur $2{,}5$ divise par $2$ avant de soustraire $1$ ; $4$ ajoute $1$ au lieu de le soustraire ; $6$ oublie de diviser par $2$.

---

## Réglages Wooclap suggérés

- Affichage des résultats : après clôture du vote, pas en direct.
- Chronomètre : 30 à 45 secondes par question.
- Ordre : Q1, Q2. Q1 prépare la définition de la croissance (S.3) ; Q2 prépare les exercices de transfert, où l'on connaît la sortie et cherche l'entrée.
