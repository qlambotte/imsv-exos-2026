Mettre un problème en équationO1
Quand l'utiliser ?

Dès qu’un énoncé décrit une situation par des mots et demande une valeur inconnue.

Déplier le corrigé — étapes, exemple, piège
Étapes
  1. Choisis l’inconnue et note son unité (xx = …, en …).
  2. Traduis chaque relation de l’énoncé en une égalité ; respecte l’ordre des mots.
  3. Résous l’équation obtenue par transformations identiques.
  4. Contrôle que la solution est admissible dans le contexte (signe, domaine, ordre de grandeur).
  5. Énonce la réponse avec son unité.
Exemple

« Le double d’un nombre, diminué de 55, vaut 1717. » Inconnue xx : 2x−5=17⇒2x=22⇒x=112x - 5 = 17 \Rightarrow 2x = 22 \Rightarrow x = 11.

Le piège

Traduire dans le mauvais ordre — 2(x−5)2(x - 5) pour « le double, diminué de 55 » au lieu de 2x−52x - 5 — ou oublier de vérifier que la réponse a un sens.

Résoudre une équation ou une inéquation du premier degréO2
Quand l'utiliser ?

Dès qu’une (in)égalité met en jeu une inconnue à la puissance 11.

Déplier le corrigé — étapes, exemple, piège
Étapes
  1. Développe les produits et supprime les fractions (multiplie les deux membres par le dénominateur commun).
  2. Regroupe les termes en xx d’un côté, les nombres de l’autre, par transformations identiques aux deux membres.
  3. Isole xx en divisant par son coefficient.
  4. Pour une inéquation : si tu multiplies ou divises par un nombre négatif, inverse le sens de l’inégalité.
  5. Écris l’ensemble solution (Sol={…}\mathrm{Sol} = \{\dots\}, ou un intervalle pour une inéquation).
Exemple

−2x+3≤11⇒−2x≤8⇒x≥−4-2x + 3 \le 11 \Rightarrow -2x \le 8 \Rightarrow x \ge -4 (division par −2-2 : le sens s’inverse). Sol=[−4,+∞[\mathrm{Sol} = [-4,\, +\infty[.

Le piège

Changer un terme de membre sans changer son signe ; diviser par un négatif sans inverser l’inégalité.

Résoudre un système linéaire (substitution ou élimination)O3
Quand l'utiliser ?

Dès qu’il faut trouver plusieurs inconnues satisfaisant plusieurs équations en même temps.

Déplier le corrigé — étapes, exemple, piège
Étapes
  1. Substitution : isole une inconnue dans une équation, remplace-la dans l’autre, résous, puis remonte la chaîne.
  2. Élimination : multiplie une équation pour opposer les coefficients d’une inconnue, additionne terme à terme pour la faire disparaître, résous, puis remonte.
  3. Donne la solution comme un couple (x,y)(x, y).
  4. Vérifie le couple dans les deux équations de départ.
Exemple

{vA+vB=10010vA+20vB=1600\begin{cases} v_A + v_B = 100 \\ 10 v_A + 20 v_B = 1600 \end{cases} : substitution vA=100−vBv_A = 100 - v_B donne vB=60v_B = 60, vA=40v_A = 40. Sol={(40,60)}\mathrm{Sol} = \{(40, 60)\}.

Le piège

Donner un seul nombre au lieu d’un couple ; en élimination, ne multiplier qu’un membre de l’équation.

Équation d'une droite : pente et ordonnée à l'origineO4
Quand l'utiliser ?

Dès qu’il faut trouver, lire ou interpréter l’équation y=mx+py = mx + p d’une droite.

Déplier le corrigé — étapes, exemple, piège
Étapes
  1. À partir de deux points (x1,y1)(x_1, y_1) et (x2,y2)(x_2, y_2) (avec x1≠x2x_1 \ne x_2), calcule la pente m=y2−y1x2−x1m = \dfrac{y_2 - y_1}{x_2 - x_1}.
  2. Déduis l’ordonnée à l’origine avec un point : p=y1−mx1p = y_1 - m\, x_1.
  3. Écris l’équation y=mx+py = mx + p et vérifie avec l’autre point.
  4. Interprète : mm est un taux de variation (de yy par unité de xx) ; son signe dit si la droite croît, décroît ou est constante. pp est la valeur de yy pour x=0x = 0.
Exemple

Par (1,3)(1, 3) et (3,7)(3, 7) : m=7−33−1=2m = \dfrac{7 - 3}{3 - 1} = 2 ; p=3−2⋅1=1p = 3 - 2 \cdot 1 = 1. D’où y=2x+1y = 2x + 1.

Le piège

Inverser le rapport de la pente ; oublier qu’une droite verticale (x=cx = c) n’a pas de pente et n’est pas une fonction.

Proportionnalité, taux et conversionsO4
Quand l'utiliser ?

Dès que deux grandeurs varient « par unité de » l’une l’autre : prix par kg, distance par heure, masse par volume…

Déplier le corrigé — étapes, exemple, piège
Étapes
  1. Vérifie que les grandeurs sont directement proportionnelles : y=kxy = kx (la relation passe par l’origine). Un coût fixe la rend affine (y=kx+py = kx + p) : plus de règle de trois.
  2. Identifie le facteur kk (le taux), avec son unité.
  3. Pour convertir un taux, passe par les unités de base (11 km =1000= 1000 m, 11 h =3600= 3600 s, …).
  4. Contrôle par l’ordre de grandeur : le résultat va-t-il dans le sens attendu (plus grand / plus petit) ?
Exemple

7272 km/h =72000 m3600 s=20= \dfrac{72\,000 \text{ m}}{3\,600 \text{ s}} = 20 m/s. Prix à 33 €/kg : p=3mp = 3m (linéaire) ; avec 55 € de livraison : p=3m+5p = 3m + 5 (affine).

Le piège

Appliquer une règle de trois à une relation affine (avec coût fixe) ; se tromper de sens (multiplier au lieu de diviser) dans une conversion.

Résoudre une équation du second degré (discriminant)O5
Quand l'utiliser ?

Dès qu’une équation se ramène à la forme ax2+bx+c=0ax^2 + bx + c = 0 (avec a≠0a \ne 0).

Déplier le corrigé — étapes, exemple, piège
Étapes
  1. Mets l’équation sous forme développée ax2+bx+c=0ax^2 + bx + c = 0 (tout d’un même côté).
  2. Calcule le discriminant Δ=b2−4ac\Delta = b^2 - 4ac.
  3. Selon son signe : Δ>0\Delta > 0 → deux solutions x1,2=−b±Δ2ax_{1,2} = \dfrac{-b \pm \sqrt{\Delta}}{2a} ; Δ=0\Delta = 0 → une solution x=−b2ax = \dfrac{-b}{2a} ; Δ<0\Delta < 0 → aucune solution réelle.
  4. Écris l’ensemble solution.
Exemple

x2−5x+6=0x^2 - 5x + 6 = 0 : Δ=25−24=1>0\Delta = 25 - 24 = 1 > 0, donc x1,2=5±12x_{1,2} = \dfrac{5 \pm 1}{2}, soit x=3x = 3 ou x=2x = 2. Sol={2,3}\mathrm{Sol} = \{2, 3\}.

Le piège

Se tromper de signe dans −b-b ; oublier le 2a2a au dénominateur ; conclure sur la taille de Δ\Delta plutôt que sur son signe.
