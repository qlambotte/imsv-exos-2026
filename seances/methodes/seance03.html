Mettre un problème en équationO1
Quand l'utiliser ?

Dès qu’un énoncé décrit une situation par des mots et demande une valeur inconnue.

Déplier le corrigé — étapes, exemple, piège
Étapes
  1. Lis l’énoncé jusqu’au bout et repère la question posée : c’est elle qui désigne l’inconnue.
  2. Choisis l’inconnue et écris ce qu’elle représente, avec son unité : « Soit xx … (en …) ». S’il y a plusieurs grandeurs inconnues, exprime-les si possible à l’aide d’une seule.
  3. Traduis chaque relation de l’énoncé, morceau par morceau et dans l’ordre des mots : « augmenté de » devient ++, « diminué de » devient −-, « le double de » devient 2⋅2 \cdot, « vaut » ou « est égal à » devient ==.
  4. Vérifie que les deux membres de l’équation s’expriment dans la même unité.
  5. Résous l’équation obtenue par transformations identiques.
  6. Contrôle que la solution est admissible dans le contexte (signe, domaine, ordre de grandeur) ; écarte celles qui n’ont pas de sens.
  7. Réponds à la question par une phrase, avec l’unité.
Exemple

« Un flacon de sérum contient 500500 mL. Après 33 heures de perfusion à débit constant, il reste 140140 mL. Quel est le débit de la perfusion ? »

La question porte sur le débit. Soit dd le débit de la perfusion, en mL/h. En 33 heures, le flacon perd 3d3d mL ; il en reste 140140 : l’équation est 500−3d=140500 - 3d = 140, et ses deux membres sont en mL. On résout : 500−3d=140⇔−3d=−360⇔d=120.500 - 3d = 140 \;\Leftrightarrow\; -3d = -360 \;\Leftrightarrow\; d = 120. Donc Sol={120}\mathrm{Sol} = \{120\}. Vérification : 500−3⋅120=140500 - 3 \cdot 120 = 140. ✓ Un débit est positif et le flacon ne peut pas perdre plus que son contenu (3⋅120=360≤5003 \cdot 120 = 360 \le 500) : la solution est admissible. La perfusion a un débit de 120120 mL/h.

Le piège

Traduire dans le mauvais ordre — 2(x−5)2(x - 5) pour « le double, diminué de 55 » au lieu de 2x−52x - 5 ; oublier l’unité de l’inconnue ou de la réponse ; oublier de vérifier que la réponse a un sens dans le contexte.

Résoudre une équation ou une inéquation du premier degréO2
Quand l'utiliser ?

Dès qu’une (in)égalité met en jeu une inconnue à la puissance 11.

Déplier le corrigé — étapes, exemple, piège
Étapes
  1. Développe les produits : distribue le facteur sur chaque terme de la parenthèse.
  2. S’il y a des fractions, multiplie chaque terme des deux membres par le dénominateur commun.
  3. Regroupe les termes en xx dans un membre et les nombres dans l’autre, en ajoutant ou en soustrayant le même terme aux deux membres : un terme qui change de membre change de signe.
  4. Réduis chaque membre : tu obtiens une égalité (ou une inégalité) de la forme ax=bax = b.
  5. Divise les deux membres par aa (avec a≠0a \ne 0) :
    • pour une équation, x=bax = \dfrac{b}{a} et Sol={ba}\mathrm{Sol} = \left\{\dfrac{b}{a}\right\} ;
    • pour une inéquation, le sens est conservé si a>0a > 0 et inversé si a<0a < 0.
  6. Si les termes en xx se sont éliminés (il reste 0⋅x=b0 \cdot x = b) : l’égalité est toujours vraie si b=0b = 0, et Sol=ℝ\mathrm{Sol} = \mathbb{R} ; elle n’est jamais vraie si b≠0b \ne 0, et Sol=⌀\mathrm{Sol} = \varnothing.
  7. Écris l’ensemble solution : un ensemble à un élément pour une équation, un intervalle pour une inéquation (crochet fermé pour ≤\le ou ≥\ge, ouvert pour << ou >>).
  8. Vérifie : remplace xx par la solution dans l’équation de départ ; pour une inéquation, teste une valeur de l’intervalle et une valeur hors de l’intervalle.
Exemple

Résolvons −2x+3≤11-2x + 3 \le 11. On soustrait 33 aux deux membres, puis on divise par −2-2, qui est négatif : le sens s’inverse. −2x+3≤11⇔−2x≤8⇔x≥−4.-2x + 3 \le 11 \;\Leftrightarrow\; -2x \le 8 \;\Leftrightarrow\; x \ge -4. Donc Sol=[−4,+∞[\mathrm{Sol} = [-4,\, +\infty[. Vérification : pour x=0x = 0, on a 3≤113 \le 11, qui est vrai ; pour x=−5x = -5, on a 13≤1113 \le 11, qui est faux. ✓

Le piège

Changer un terme de membre sans changer son signe ; diviser par un nombre négatif sans inverser le sens de l’inégalité ; ne multiplier par le dénominateur commun qu’un seul terme.

Résoudre un système linéaire (substitution ou élimination)O2
Quand l'utiliser ?

Dès qu’il faut trouver plusieurs inconnues satisfaisant plusieurs équations en même temps.

Déplier le corrigé — étapes, exemple, piège
Étapes
  1. Écris chaque équation sous la forme ax+by=cax + by = c et numérote-les (1)(1) et (2)(2).
  2. Substitution — pratique quand une inconnue a pour coefficient 11 ou −1-1 :
    • isole cette inconnue dans l’une des équations ;
    • remplace-la dans l’autre équation : il reste une équation à une inconnue ;
    • résous cette équation ;
    • reporte la valeur trouvée dans l’expression isolée pour obtenir l’autre inconnue.
  3. Élimination — pratique quand les coefficients d’une inconnue sont opposés ou multiples l’un de l’autre :
    • multiplie chaque terme des deux membres d’une équation (ou des deux) pour que les coefficients d’une inconnue deviennent opposés ;
    • additionne les deux équations terme à terme : cette inconnue disparaît ;
    • résous l’équation obtenue, puis reporte la valeur dans une équation de départ.
  4. Conclus selon ce qu’il reste :
    • une valeur pour chaque inconnue : une seule solution, Sol={(x,y)}\mathrm{Sol} = \{(x,\, y)\} ; les deux droites sont sécantes ;
    • une égalité toujours fausse (par exemple 0=20 = 2) : aucune solution, Sol=⌀\mathrm{Sol} = \varnothing ; les droites sont parallèles et distinctes (exemple : x+y=4x + y = 4 et x+y=6x + y = 6) ;
    • une égalité toujours vraie (0=00 = 0) : une infinité de solutions, Sol={(x,y)∣ax+by=c}\mathrm{Sol} = \{(x, y) \mid ax + by = c\} ; les droites sont confondues (exemple : x+y=4x + y = 4 et 2x+2y=82x + 2y = 8).
  5. Vérifie le couple dans les deux équations de départ.
  6. Interprète dans le contexte : unité de chaque inconnue, et solution admissible (signe, domaine).
Exemple

Résolvons {vA+vB=100(1)10vA+20vB=1600(2)\begin{cases} v_A + v_B = 100 & (1) \\ 10\, v_A + 20\, v_B = 1600 & (2) \end{cases} Dans (1)(1), le coefficient de vAv_A vaut 11 : on isole vA=100−vBv_A = 100 - v_B et on remplace dans (2)(2). 10(100−vB)+20vB=1600⇔1000+10vB=1600⇔vB=60.10(100 - v_B) + 20\, v_B = 1600 \;\Leftrightarrow\; 1000 + 10\, v_B = 1600 \;\Leftrightarrow\; v_B = 60. On reporte : vA=100−60=40v_A = 100 - 60 = 40. Donc Sol={(40,60)}\mathrm{Sol} = \{(40,\, 60)\}. Vérification : 40+60=10040 + 60 = 100 ✓ et 10⋅40+20⋅60=400+1200=160010 \cdot 40 + 20 \cdot 60 = 400 + 1200 = 1600 ✓. Si vAv_A et vBv_B sont des volumes en mL, il faut prélever 4040 mL de AA et 6060 mL de BB.

Le piège

Donner un seul nombre au lieu d’un couple ; en élimination, ne multiplier qu’un membre de l’équation ; conclure x=0x = 0 quand on obtient 0=00 = 0, ou confondre « aucune solution » et « une infinité de solutions ».

Équation d'une droite : pente et ordonnée à l'origineO4
Quand l'utiliser ?

Dès qu’il faut trouver, lire ou interpréter l’équation y=mx+py = mx + p d’une droite.

Déplier le corrigé — étapes, exemple, piège
Étapes
  1. Pars de deux points (x1,y1)(x_1, y_1) et (x2,y2)(x_2, y_2) de la droite et compare leurs abscisses.
  2. Si x1=x2x_1 = x_2, la droite est verticale : son équation est x=x1x = x_1. Elle n’a pas de pente et ne s’écrit pas sous la forme y=mx+py = mx + p.
  3. Sinon, calcule la pente m=y2−y1x2−x1m = \dfrac{y_2 - y_1}{x_2 - x_1}, en gardant le même ordre des points au numérateur et au dénominateur. Si m=0m = 0, la droite est horizontale, d’équation y=y1y = y_1.
  4. Déduis l’ordonnée à l’origine en remplaçant un point dans y=mx+py = mx + p : p=y1−mx1p = y_1 - m\, x_1.
  5. Écris l’équation y=mx+py = mx + p et vérifie avec l’autre point.
  6. Interprète :
    • mm est le taux de variation : quand xx augmente de 11, yy varie de mm (en unité de yy par unité de xx) ; la droite croît si m>0m > 0, décroît si m<0m < 0 et est constante si m=0m = 0 ;
    • pp est la valeur de yy pour x=0x = 0 (souvent la valeur initiale).
  7. Pour deux droites y=mx+py = mx + p et y=m′x+p′y = m'x + p' :
    • si m≠m′m \ne m', elles sont sécantes ; leur point d’intersection se trouve en résolvant le système formé par les deux équations ;
    • si m=m′m = m' et p≠p′p \ne p', elles sont parallèles ; si m=m′m = m' et p=p′p = p', elles sont confondues ;
    • si m⋅m′=−1m \cdot m' = -1, elles sont orthogonales.
Exemple

Par (1,3)(1, 3) et (3,7)(3, 7) : les abscisses sont différentes, la droite n’est donc pas verticale. m=7−33−1=42=2,p=3−2⋅1=1.m = \dfrac{7 - 3}{3 - 1} = \dfrac{4}{2} = 2, \qquad p = 3 - 2 \cdot 1 = 1. D’où y=2x+1y = 2x + 1. Vérification avec (3,7)(3, 7) : 2⋅3+1=72 \cdot 3 + 1 = 7. ✓ La pente 22 est positive : quand xx augmente de 11, yy augmente de 22. La droite coupe l’axe des ordonnées en (0,1)(0, 1).

En revanche, par (2,1)(2, 1) et (2,5)(2, 5), les abscisses sont égales : la droite est verticale, d’équation x=2x = 2.

Le piège

Inverser le rapport de la pente, ou mélanger l’ordre des points entre numérateur et dénominateur ; chercher une pente à une droite verticale (x=cx = c), qui n’en a pas.

Proportionnalité, taux et conversionsO4
Quand l'utiliser ?

Dès que deux grandeurs varient « par unité de » l’une l’autre : prix par kg, distance par heure, masse par volume…

Déplier le corrigé — étapes, exemple, piège
Étapes
  1. Teste la proportionnalité : les grandeurs sont directement proportionnelles si y=kxy = kx, c’est-à-dire si le quotient yx\dfrac{y}{x} est le même pour toutes les valeurs (la relation passe par l’origine).
  2. Si c’est le cas, identifie le facteur k=yxk = \dfrac{y}{x} (le taux), avec son unité.
  3. Calcule : y=kxy = kx pour trouver yy, ou x=ykx = \dfrac{y}{k} pour trouver xx (règle de trois).
  4. Si la relation contient un terme fixe (forfait, coût de livraison…), elle s’écrit y=kx+py = kx + p avec p≠0p \ne 0 : elle est affine et non proportionnelle. Remplace alors directement xx dans la relation, sans règle de trois.
  5. Pour convertir un taux, écris-le comme une fraction avec ses unités, remplace chaque unité par sa valeur en unités de base (11 km =1000= 1000 m, 11 h =3600= 3600 s, …), puis simplifie.
  6. Contrôle par l’ordre de grandeur : le résultat va-t-il dans le sens attendu (plus grand ou plus petit) ?
Exemple

Conversion. 7272 km/h =72 km1 h=72000 m3600 s=20= \dfrac{72 \text{ km}}{1 \text{ h}} = \dfrac{72\,000 \text{ m}}{3\,600 \text{ s}} = 20 m/s. Contrôle : 11 m/s vaut 3,63{,}6 km/h, donc le nombre en m/s doit être plus petit. ✓

Proportionnalité. À 33 €/kg, le prix vaut p=3mp = 3m : 22 kg coûtent 66 € et 44 kg coûtent 1212 €, soit le double. Avec 55 € de livraison, p=3m+5p = 3m + 5 : 22 kg coûtent 1111 € et 44 kg coûtent 1717 €, et non 2222 € ; la relation est affine, une règle de trois donnerait un résultat faux.

Le piège

Appliquer une règle de trois à une relation affine (avec coût fixe) ; se tromper de sens (multiplier au lieu de diviser) dans une conversion ; oublier l’unité du taux.

Résoudre une équation du second degré (discriminant)O5
Quand l'utiliser ?

Dès qu’une équation se ramène à la forme ax2+bx+c=0ax^2 + bx + c = 0 (avec a≠0a \ne 0).

Déplier le corrigé — étapes, exemple, piège
Étapes
  1. Mets l’équation sous la forme ax2+bx+c=0ax^2 + bx + c = 0 : développe, passe tous les termes dans un même membre, puis réduis.
  2. Identifie aa, bb et cc avec leur signe.
  3. Si c=0c = 0 ou b=0b = 0, le discriminant n’est pas nécessaire :
    • si c=0c = 0, mets xx en évidence : x(ax+b)=0x(ax + b) = 0, donc x=0x = 0 ou x=−bax = -\dfrac{b}{a} ;
    • si b=0b = 0, isole x2=−cax^2 = -\dfrac{c}{a} et prends les deux racines carrées si ce nombre est positif.
  4. Sinon, calcule le discriminant Δ=b2−4ac\Delta = b^2 - 4ac.
  5. Conclus selon son signe :
    • Δ>0\Delta > 0 : deux solutions, x1=−b−Δ2ax_1 = \dfrac{-b - \sqrt{\Delta}}{2a} et x2=−b+Δ2ax_2 = \dfrac{-b + \sqrt{\Delta}}{2a} ; la parabole y=ax2+bx+cy = ax^2 + bx + c coupe l’axe des xx en deux points ;
    • Δ=0\Delta = 0 : une solution, x=−b2ax = -\dfrac{b}{2a} ; la parabole touche l’axe des xx en un seul point, son sommet ;
    • Δ<0\Delta < 0 : aucune solution réelle, Sol=⌀\mathrm{Sol} = \varnothing ; la parabole ne coupe pas l’axe des xx.
  6. Écris l’ensemble solution et vérifie une solution dans l’équation de départ.
  7. En contexte, ne garde que les solutions admissibles (signe, domaine).
Exemple

Résolvons x2−5x+6=0x^2 - 5x + 6 = 0. On a a=1a = 1, b=−5b = -5, c=6c = 6, donc Δ=(−5)2−4⋅1⋅6=25−24=1>0:deux solutions.\Delta = (-5)^2 - 4 \cdot 1 \cdot 6 = 25 - 24 = 1 > 0 : \text{deux solutions.} x1=5−12=2,x2=5+12=3.x_1 = \dfrac{5 - 1}{2} = 2, \qquad x_2 = \dfrac{5 + 1}{2} = 3. Donc Sol={2,3}\mathrm{Sol} = \{2,\, 3\}. Vérification : 22−5⋅2+6=4−10+6=02^2 - 5 \cdot 2 + 6 = 4 - 10 + 6 = 0. ✓

Pour x2−6x+9=0x^2 - 6x + 9 = 0, Δ=36−36=0\Delta = 36 - 36 = 0 : une seule solution, x=62=3x = \dfrac{6}{2} = 3, et Sol={3}\mathrm{Sol} = \{3\}. Pour x2+x+1=0x^2 + x + 1 = 0, Δ=1−4=−3<0\Delta = 1 - 4 = -3 < 0 : Sol=⌀\mathrm{Sol} = \varnothing.

Le piège

Se tromper de signe dans −b-b ; oublier le 2a2a au dénominateur ; conclure sur la taille de Δ\Delta plutôt que sur son signe ; oublier la solution x=0x = 0 en divisant par xx au lieu de le mettre en évidence.
